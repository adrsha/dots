# Caveman Help — quick reference

Use when user asks `/caveman-help`, "caveman help", "what caveman commands", or "how use caveman". One-shot only; do not change active skills.

## Modes

- `/caveman lite`: drop filler; keep full sentences.
- `/caveman` or `/caveman full`: drop articles/filler/pleasantries/hedging; fragments OK.
- `/caveman ultra`: extreme prose compression; do not alter code/API/error strings.
- `/caveman wenyan-lite`: light semi-classical Chinese.
- `/caveman wenyan-full`: maximum classical terseness.
- `/caveman wenyan-ultra`: extreme classical compression.

## Skills

- `caveman`: persistent terse output.
- `caveman-commit`: conventional commit message, terse.
- `caveman-review`: one-line code review findings.
- `caveman-compress`: compress prose docs, preserve code.
- `cavecrew`: compressed delegation patterns adapted for AiTUI.

Deactivate: "stop caveman" or "normal mode".
