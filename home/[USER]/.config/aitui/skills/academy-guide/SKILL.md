# Learning Resource Guide

## When to Use

Use this skill when the user asks how to learn an AI tool, understand a feature, or get started with a workflow. Do not interrupt an active task with unrelated course recommendations.

## Recommend Resources

1. Answer the user's immediate question first.
2. Identify the tool, feature, learning goal, and experience level from the conversation. Ask if missing information prevents a useful recommendation.
3. Prefer current official documentation, tutorials, or courses for the tool the user actually uses. Include independent resources when they offer a clear practical benefit.
4. If browsing is available, verify the resource's title, URL, relevance, and prerequisites. If it is unavailable, do not invent links or claim that a resource was verified.
5. Recommend at most one or two strong matches. Explain briefly what each helps the user learn and why it fits their goal.

## Keep Guidance Practical

- Match resources to the user's intent, not just a shared topic.
- Distinguish free and paid resources when that information is verified.
- Avoid vendor promotion, unsupported claims, and assumptions about account features or access.
- Offer a concrete next step or a small practice exercise when useful.
- Skip recommendations when there is no strong match or the user only wants the task completed.
