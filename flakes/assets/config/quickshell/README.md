# Bar-free Quickshell (prototype)

On-demand panels, no persistent bar. `shell.qml` coordinates state, backend processes, and IPC. UI lives under `ui/panels/`, reusable controls under `ui/components/`, and passive desktop surfaces under `ui/desktop/`. Python implementations are in `services/`, tests in `tests/`, bundled fonts in `assets/fonts/`, and planning documents in `docs/`. The small root `backend.py` preserves existing Hyprland command bindings.

## Keyboard navigation

- **h/l** move backward/forward; **j/k** move down/up (by row in the launcher grid).
- **g / Shift+G** jump to first/last target; **Enter** activates.
- **/ or i** focuses search in launcher and wallpaper studio. Printable keys remain normal text while editing.
- **Esc** leaves text editing; another **Esc** closes the panel.
- Wallpaper studio: **Tab** switches between gallery and controls; **Ctrl+J / Ctrl+K** switch Discover/Local; **Ctrl+Enter** assigns the selected local wallpaper.

## Running after installation

Run `qs -p ~/.config/quickshell` (check installed Quickshell CLI syntax/version). Open panels through `qs ipc call shell toggleLauncher`, `toggleSidePanel`, `toggleControls`, `toggleMedia`, `toggleWallpapers`, `toggleScreenshot`, `toggleNotifications`, `togglePower`; `qs ipc call shell close` closes. Volume IPC accepts `changeVolume 5` or `changeVolume -- -5`. `toggleTodo` currently routes to dashboard, **not** task manager.

Dependencies: Python 3.9+, `uwsm app`, `hyprctl`, `nmcli`, `bluetoothctl`, `wpctl`, `playerctl`, `theme-set`; screenshots require `grim`, region selection requires `slurp`, copy/Lens requires `wl-copy` and `xdg-open`, DDC brightness requires `ddcutil` and I²C permission; video wallpapers require `mpvpaper`, `ffmpeg` and QtMultimedia; secure lock requires `hyprlock` or `swaylock`. Wallpaper folder: `~/Pictures/walls`; themes: `~/.config/theme-manager/themes`. Wallpaper studio: `qs ipc call shell toggleWallpapers`; import uses absolute path, then destination category. Local move refuses wallpapers referenced by installed themes. Deletion needs explicit in-studio confirmation and rejects files referenced by themes; rename UI not implemented. Wallhaven SFW HD search works without key; Unsplash requires `UNSPLASH_ACCESS_KEY`; Pexels image/video requires `PEXELS_API_KEY` in Quickshell process environment. Reddit unavailable without compliant OAuth access, so not implemented. Provider results preview before download; remote asset URLs are retrieved by refetching selected provider ID, constrained to HTTPS provider hosts and size limits. Wallhaven creators retain rights; inspect source page before reuse. Provider attribution saved in adjacent `.source.json` and moves with media. Source API docs: [Wallhaven](https://wallhaven.cc/help/api), [Unsplash](https://unsplash.com/documentation), [Pexels](https://www.pexels.com/api/documentation/). Run `python3 -m unittest -q test_desktop_services test_wallpaper_store test_wallpaper_sources` and `qmllint shell.qml DesktopOsd.qml NotificationCard.qml`. Most missing system tools report feedback; launcher validates desktop IDs.

Hyprland uses **Lua** (`hyprctl systeminfo`: `configProvider: lua`); `ALT+Space` targets Quickshell launcher. Lock binding routes through `backend.py action lock` at `SUPER+SHIFT+CTRL+L`. `Print` opens screenshot chooser; `Super+Print` saves focused window, `Shift+Print` saves focused display, `Ctrl+Print` selects region, copies it, then opens Google Images. Click Lens camera and upload/paste manually—no official public Lens upload API is used. Install `grim` for captures and `slurp` for region selection; both were absent during validation. `wl-copy` and `xdg-open` are available. Screenshots save under `~/Pictures/Screenshots`. DDC brightness uses `ddcutil` VCP 0x10 on its default/first detected monitor, with 5% steps, cross-process lock, and bounds checks; it does not change all displays or laptop backlights. `ddcutil getvcp 10 --brief` read 40/100 on MSI G255F; hardware writes were not tested. Corrected XF86 brightness directions in Lua; reload/restart Hyprland to apply. OSD is passive and auto-hides. `qmllint shell.qml DesktopOsd.qml` and `python3 -m unittest -q test_desktop_services test_wallpaper_store test_wallpaper_sources` passed (24 tests); inspect screenshot chooser, OSD rendering, Lens paste, and DDC write on compositor. Keep fallback access while testing; no compositor reload or external-service replacement performed.

under UWSM's graphical session. Do not additionally run `qs -d` from Hyprland.
Launcher applications use `uwsm app` so restarting the shell does not kill them.
